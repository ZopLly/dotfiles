# Происхождение коллекции обоев

Файлы хранятся без перекодирования, имена определяются SHA-256.
Список контрольных сумм и размеров находится в catalog.json.

Шесть прежних изображений взяты из существующих assets Niri, сверены с исходным
набором и установленным снимком. Существующее происхождение пользовательских изображений
не переопределяется; они сохранены для личного окружения.

Пять дополнительных изображений:
- Ван Гог, «Звёздная ночь»: Wikimedia Commons, File:Van_Gogh_-_Starry_Night_-_Google_Art_Project.jpg; источник указан в hyprstack-shell/docs/media/README.md.
- Хокусай, «Большая волна в Канагаве»: сохранённая копия из Wikimedia Commons; произведение указано автором Hyprstack со ссылкой https://www.artic.edu/artworks/24645.
- Моне, «Кувшинки»: сохранённая копия из Wikimedia Commons; произведение указано автором Hyprstack со ссылкой https://www.artic.edu/artworks/16568.
- Гентский алтарь: hase9awa/hyprstack-dotfiles, commit 3006acbb90a63053f88f2d4811bec622b22c1f9e, home/Pictures/wallpapers/ybietl668u6h1.png.
- Космические обои автора: тот же репозиторий и commit, home/.local/share/hyprstack/shell/assets/wallpaper.webp.

Сведения об изображениях из dotfiles сохраняют условия их исходного репозитория.
Коллекция предназначена для локального оформления и здесь не публикуется.
