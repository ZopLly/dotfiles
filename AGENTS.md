# Порядок работы с конфигурацией

По требованию пользователя все изменения сначала готовятся в отдельном локальном
Git-репозитории `/home/andrew/dotfiles/niri-staging`.

- Работать с конфигами и связанными скриптами только в `niri-staging`.
- Сохранять законченные изменения коммитами в этом репозитории.
- Перед применением показать пользователю изменения и результаты проверок.
- Применять изменения в `/home/andrew/dotfiles` и `~/.config` только после явной
  команды пользователя на применение проверенных изменений.
- Не запускать установщики, переключатели тем и скрипты, меняющие рабочее окружение,
  в ходе подготовки или проверки. Проверять Niri через
  `niri validate -c /home/andrew/dotfiles/niri-staging/niri/config.kdl`.
- Не добавлять вложенный репозиторий `niri-staging` в родительский Git-репозиторий.
- Репозиторий локальный; публикация и push требуют поручения пользователя.

Сам этот файл закрепляет согласованный порядок работы; его создание не является
применением изменений конфигурации.
