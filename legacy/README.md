# Прежнее окружение

Здесь отделены Waybar, Eww, Kitty, Swaylock и прежняя конфигурация Niri.
Основная оболочка находится в `../quickshell/`. Музыкальный обработчик основной
оболочки находится в `../quickshell/cava_stream.py`, а не в Waybar.

`deployment/` содержит исторические варианты внешнего вида для старых скриптов
применения. Они не запускаются автоматически.

Установщик по умолчанию не устанавливает Waybar/Eww. Явный вариант
`./install.sh --shell legacy --apply` сохраняется для прежнего окружения.

Не запускайте старые конфиги как обновление основной оболочки.
