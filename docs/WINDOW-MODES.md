# Режим окон текущего рабочего стола

В staging добавлен переключатель в быстрых настройках: «Свободные окна на этом столе» / «Вернуть тайлинг этого стола». Он работает только в проверенном временном предпросмотре. Основная сессия не изменена.

Перед переключением сохраняются ID окон и процесса, порядок колонок и окон внутри колонок, размеры. Уже плавающие окна и диалоги остаются такими. Новые обычные окна на свободном столе также переводятся в свободный режим. При возврате закрытые окна пропускаются, перемещённые на другой стол не возвращаются насильно; новые окна остаются доступными и получают колонки после прежних.

Снимок хранится атомарно с правами 0600 в `window-modes.json` состояния предпросмотра и привязан к сокету конкретной сессии Niri. Перезапуск панели не теряет снимок; другой сеанс не получает старые ID окон. При ошибке восстановления снимок остаётся для повторной попытки. Повреждённые данные отклоняются до отправки команд восстановления.

Почему нужен контроллер: проверка на установленном Niri 26.04 показала, что простое включение floating и обратное переключение меняет порядок колонок. Контроллер сначала собирает отдельные колонки, затем возвращает окна в их группы и размеры. Фокус возвращается к последнему выбранному окну этого стола, в том числе когда переключение вызвано из меню.

Код: `quickshell/applications/window_modes.py`; интеграция через существующую службу приложений и `QuickSettingsHeader.qml`. Поддерживаются штатные перемещение и изменение размера мышью с модификатором Niri, а действия полного экрана, разворачивания и закрытия доступны через список окон. Сворачивание пока не реализовано: отдельной штатной команды Niri нет.

Проверки: пять коротких Python-сценариев, существующие проверки службы приложений, QtTest переходов шторки и реальный тест `./applications-preview.sh --window-modes`. Последний проверяет колонки, несколько окон в одной колонке, восстановление размеров после изменения ширины плавающего окна и независимость другого стола. Размеры сравниваются с допуском 2 логических пикселя из-за округления при масштабе 1.6. Исходные пропорции колонок после изменения разрешения, исходно полноэкранные окна и переключение мониторов во время свободного режима требуют дополнительной проверки перед установкой.

Запуск для просмотра: `./applications-preview.sh`. Alt+E открывает быстрые настройки внутри предпросмотра; модификатор вложенного Niri — Alt. Alt+Shift+E завершает просмотр.

В этом же обновлении значки уменьшены примерно на 30% от исходного размера: панель 23 → 16, меню 36 → 25 логических пикселей. Области нажатия сохранены.
