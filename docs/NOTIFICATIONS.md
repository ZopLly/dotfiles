# Уведомления и блокировка — следующий этап

Применено 22 октября 2026: `20261022-211100-integrated`. Предыдущий снимок сохранён для отката.

- Кнопка колокольчика в правом островке открывает компактную шторку: текущие сообщения, история Mako, закрытие одного или всех текущих сообщений, «Не беспокоить».
- Сохраняется один сервер Mako. Оболочка читает его D-Bus и не сохраняет тексты на диск. История ограничена возможностями текущего Mako; после перезапуска сервера она исчезает. В шторке показываются до 50 сообщений в разделе.
- Предпросмотр содержит только демонстрационное сообщение и не подключается к личным уведомлениям.
- Отдельный модуль gtklock 4 показывает до трёх текущих сообщений справа сверху, только для чтения. Действий, запуска приложений и изменений аутентификации нет. При недоступности Mako область скрывается; блокировка продолжает работать.
- Фон блокировки берётся из независимого выбора обоев. Палитра не меняет его. При наличии кеша используется размытие; иначе исходное изображение. Размытие готовится после подтверждённого выбора обоев, вне пути блокировки/перехода в сон.
- Unit swayidle подготовлен с постоянным путём `~/.config/gtklock/scripts/lock.sh`, чтобы больше не вызывать старый снимок. Unit включён вместе с новым релизом; восстановление прежней службы включено в откат и проверено отдельным тестом. Ограничение запуска только в Niri сохранено.

Проверки: отдельная D-Bus-шина с настоящим Mako (доставка, история, DND, закрытие); тесты кеша/независимых обоев; fake gtklock для сериализации и ошибок; GTK-тест отображения без блокировки; Qt-тест шторки; полный запуск в отдельном Niri и снимок шторки. Реальная блокировка, сон и возобновление этой версии на основном сеансе пока не проверялись.
