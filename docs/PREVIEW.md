# Предпросмотр отдельным окном

```sh
cd ~/dotfiles/niri-staging
./preview.sh
```

По умолчанию запускается **Quickshell** с новой верхней панелью и виджетами.
Подробнее: [QUICKSHELL.md](QUICKSHELL.md).

- Alt+T — терминал, Alt+1 — пространство с начальным терминалом.
- Alt+E — системная шторка, Alt+Shift+M — календарь и плеер.
- Alt+Space — широкое меню Fuzzel; выбор приложения в тесте не запускает его.
- Alt+Shift+E — выход из тестового Niri; Ctrl+C в исходном терминале также останавливает его.

Предыдущая оболочка:

```sh
./preview.sh --legacy
```

Каждый запуск создаёт /tmp/niri-preview-… с копиями конфигов, отдельными HOME,
XDG-каталогами, runtime-сокетами и D-Bus-шиной без автозапуска системных сервисов.
Терминал — bash без пользовательских стартовых файлов. Основной автозапуск,
конфиги и SSH-ключи не затрагиваются. Это не контейнер безопасности: команды,
вручную введённые в тестовый терминал, выполняются с правами пользователя.

Системное управление в тесте отключено, значения звука и сети демонстрационные.
MPRIS-плееры основной сессии не подключены к отдельной D-Bus-шине.
Текущие GIF-обои воспроизводятся отдельным awww-daemon.
Физический монитор и его масштаб здесь не тестируются: экран называется winit.

```sh
./preview.sh --check   # подготовка и проверка без окна
./preview.sh --smoke   # около 18 секунд, тестовый плеер, снимки панелей и выход
```

Путь к журналам печатается в терминале. В папке предпросмотра: preview.log,
components.log, wallpaper-status, desktop.png, center.png, right.png, fuzzel.png,
mpris-actions.jsonl. Файлы остаются в /tmp для диагностики.
