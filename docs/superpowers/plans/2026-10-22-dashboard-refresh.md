# План реализации дашборда

Выполнять в текущем staging; пользователь разрешил самостоятельное последовательное выполнение без повторных согласований.

1. Добавить проверку реальных метрик на временных /proc-данных; реализовать ограниченный сборщик и контроллер с остановкой при закрытии панели.
2. Добавить адаптивные карточки дашборда и четыре раздела, используя существующие CalendarCard, MediaCard, WeatherCard. Сохранить редактор модулей.
3. Заменить содержимое центральной шторки на Dashboard; не менять рабочую сессию.
4. Проверить Qt и отдельный Niri; подготовить реальные снимки интерфейса.
5. Подготовить два статических макета блокировки для выбора без аутентификации и захвата сессии.
6. Проверить код и сохранить относящиеся к этапу изменения локальным коммитом, показать результат.
