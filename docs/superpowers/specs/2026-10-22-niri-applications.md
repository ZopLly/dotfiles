# Островок приложений и главное меню

Продолжение согласованного окружения: отдельный компактный островок справа от рабочих столов; одно приложение — один значок, счётчик окон, выделение активного, список окон при нескольких окнах и меню переполнения. Изначально видны окна всех рабочих столов; доступен фильтр текущего экрана/рабочего стола. Меню под левым островком: поиск установленных приложений, избранные Firefox, Alacritty, ChatGPT, Happ и переход к отдельному окну оформления. Открытие одной шторки закрывает другую. Escape и щелчок снаружи закрывают меню, клавиатура работает в поиске/списках.

Связь с Niri отдельным процессом: события окон инициируют обновления, резервное обновление раз в 30 секунд. Метаданные установленных приложений читаются через Gio. Сопоставление по desktop ID и StartupWMClass, без неоднозначных эвристик. Недоступные приложения скрыты из списка запуска, но неизвестные открытые окна остаются в островке. Идентичность окон определяется ID, рабочего стола — ID, а не меняющимся номером.

Действия: фокус, полный экран, для плавающих окон разворачивание до краёв, закрытие. Сворачивание не имитируется: штатного действия Niri 26.04 нет; будет рассмотрено с режимом свободных окон. Состояние полного экрана IPC не сообщает — кнопка переключает режим без ложного индикатора. Все изменения и команды управления пока разрешены только в проверенном временном предпросмотре. Запуск в нём ограничен терминалом с отдельным профилем; браузер, VPN и ChatGPT не запускаются с пустым профилем. При попытке сообщается ограничение. Настоящий запуск установленных программ подключается при отдельно разрешённом применении.

Существующие виджеты, палитры и файлы пользователя сохраняются. Работа только в niri-staging, без установки, публикации и изменений основной сессии. Пользователь подтвердил продолжение согласованного плана; повторное согласование этих решений не нужно.
