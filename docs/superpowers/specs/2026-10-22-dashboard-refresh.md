# Дашборд Niri: согласованное направление

Пользователь разрешил начинать после выбора стиля Hyprstack и состава: время, календарь, погода, музыка, рабочий стол, CPU и дополнительные показатели производительности. Сохранить существующие островки, темы, независимые обои и службы. Работа сначала в staging; применение отдельно.

Центральный островок открывает широкую адаптивную панель с разделами «Обзор», «Медиа», «Производительность», «Погода». Обзор: часы/дата и текущий рабочий стол, погода, календарь с повесткой, настоящий MPRIS-плеер и круговые индикаторы CPU/RAM/батареи. На узком экране карточки перестраиваются, доступна прокрутка. Существующий редактор модулей сохранить отдельным разделом.

Данные CPU берутся из разности счётчиков /proc/stat, RAM и swap — /proc/meminfo, uptime/load — из /proc. Первый отсчёт CPU неизвестен, не фиктивный ноль. История ограничена памятью процесса; сбор каждые две секунды только при открытой центральной панели. Не добавлять сетевых запросов сверх существующей службы погоды; сохранять её ошибки и атрибуцию. Никаких действий с аутентификацией.

Блокировка: два наглядных макета центральной/разделённой композиции, явно помеченные макетами, без захвата сессии и ввода пароля. Выбор макета пока отсутствует; текущий gtklock не заменять.

Проверки: счётчики CPU и память на временных /proc-данных; Qt-тест адаптивности и отсутствующих данных; отдельный Niri с MPRIS-моком; скриншоты обзора и производительности; проверка макетов без блокировки. Локальный коммит только относящихся к этапу изменений.
