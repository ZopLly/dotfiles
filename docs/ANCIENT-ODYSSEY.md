# Ancient Odyssey — приёмка подготовленной версии

Тема и исправления ещё не применены к рабочей сессии. Основной отчёт:
[GUI-SYSTEM-AUDIT.md](../GUI-SYSTEM-AUDIT.md). Ранние документы FIXES/QUICKSHELL
описывают предыдущие этапы; актуальные результаты новой работы находятся в отчёте.

## Безопасные проверки

```sh
niri validate -c /home/andrew/dotfiles/niri-staging/niri/config.kdl
python3 tests/check_shell.py
python3 tests/check_system_state.py
python3 tests/check_weather.py
python3 tests/check_preview.py
./preview.sh --smoke
```

Предпросмотр имеет собственные HOME/XDG/D-Bus. Аппаратные значения демонстрационные,
кнопки управления оборудованием отключены. Smoke проверяет сохранённую геометрию
трёх виджетов после перезапуска тестовой оболочки и смены вложенного масштаба.
Это не проверка физического второго монитора или drag мышью.

## После отдельного разрешения на применение

Перед применением сохранить widgets.json в постоянную приватную резервную копию,
показать diff, проверить зависимости и предусмотренный установщиком manifest.
Не запускать второй Quickshell поверх существующего; переход выполнять через
согласованный перезапуск оболочки/сессии. Waybar/Eww оставить вариантом отката.

| Проверка | Ожидаемый результат |
|---|---|
| Три капсулы, обе шторки, настройка модулей | Прежняя компоновка; выбранные модули сохраняются |
| Wi-Fi: переключение сети/радио | SSID, сигнал и иконка синхронизируются; пароль только в nmcli |
| Bluetooth | Blueman выполняет поиск/PIN; известное устройство подключается из шторки |
| Наушники | Появляются среди выходов; выбор меняет default; проверить текущий звук и pavucontrol |
| Звук/микрофон | Слайдеры, mute, аппаратные клавиши и внешние приложения синхронизируются; OSD исчезает |
| Яркость | Клавиши и слайдер управляют backlight, OSD показывает реальный процент |
| Батарея | Иконки уровня/заряда; уведомление по порогу без непрерывных повторов |
| Виджеты | Перетащить/изменить размер, перезапустить shell, затем выйти/войти: позиции и размеры прежние |
| Дисплеи | Изменить масштаб, подключить/отключить второй монитор: карточки доступны, настройки каждого экрана сохраняются |
| Темы | Odyssey → прежняя → Odyssey: палитра и обои меняются, widgets.json нет |
| Экран блокировки | Фон Odyssey и читаемый ввод; отдельная проверка после разрешения |

Wi-Fi и Bluetooth проверять только когда временный разрыв связи допустим.
Сон/перезагрузка/выключение требуют подтверждения в шторке и отдельного согласия
для испытания. Мерцание проверять по временному протоколу основного отчёта;
оно пока не считается исправленным.

## Применение только оформления

`python3 scripts/apply-odyssey.py` показывает ограниченный план без записи.
После явного поручения пользователя `--apply` устанавливает только оформление
в текущий снимок, сохраняет файлы, предыдущую тему, GTK-настройки и widgets.json
в `~/.local/state/dotfiles/theme-backups/`. Backend и аппаратные модули не меняются.
Откат: `python3 scripts/apply-odyssey.py --rollback /путь/резервной-копии --apply`.
При изменении файлов после установки откат отказывается их перезаписывать.

## Применение оставшихся исправлений оболочки

`python3 scripts/apply-shell-update.py` показывает план без записи.
После поручения пользователя `--apply` сохраняет исходные файлы и widgets.json
в `~/.local/state/dotfiles/shell-backups/`, останавливает только выбранный Quickshell,
устанавливает проверенные QML/backend и запускает ровно один экземпляр.
Тема, настройки монитора, Niri, службы и сетевое подключение не переключаются.
При сбое восстанавливаются прежние файлы и запускается прежняя оболочка.
Если виджеты сейчас перетаскиваются, применение отклоняется до завершения редактирования.
Откат: `python3 scripts/apply-shell-update.py --rollback /путь/резервной-копии --apply`.
Он возвращает версию оболочки после установки темы; сохранённые пользовательские
координаты автоматически не перезаписывает. Проверка readiness использует
read-only IPC `shell systemStatus` и маркер версии backend.
